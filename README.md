# Couples App

A full-stack web application for couples to stay connected through shared memories, notes, and interactive features online. Made to be a PWA and actively being developed.

## Tech Stack

* React
* TypeScript
* Node.js
* Express
* PostgreSQL (Supabase)
* Supabase Storage
* Tailwind CSS

## Planned Features

* Daily questions
* Shared calendar and anniversary reminders
* Mini games
* Virtual gifts
* Notifications
* Mobile/PWA support

## Running Locally

1. Clone the repository.
2. Install dependencies for both the client and server.
3. Create a Supabase project and configure your environment variables.
4. Start the backend and frontend development servers.
